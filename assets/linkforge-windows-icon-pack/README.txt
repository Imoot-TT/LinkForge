LinkForge Windows Icon Pack

Logo source:
- The selected second ribbon logo is preserved.
- All production PNG/ICO assets use transparent backgrounds.
- No square background tile has been added.

Files:
- PNG/LinkForge_Logo_1024.png: master transparent square logo.
- PNG/LinkForge_<size>.png: raster exports at 16, 20, 24, 32, 40, 48, 64, 96, 128, 150, 192, 256, 512, and 1024 px.
- ICO/LinkForge.ico: multi-resolution Windows application icon.
- ICO/LinkForge_Setup.ico: installer icon copy.
- ICO/LinkForge_DesktopShortcut.ico: desktop shortcut icon copy.
- Windows_Assets/: common Windows tile/store image sizes.

Suggested use:
- Windows executable / desktop shortcut / installer: use the matching .ico file.
- App UI, documentation, or packaging systems that accept PNG: choose the matching PNG size.
- Keep the 1024 px master as the source for future exports.

Note:
The source artwork is a rendered 3D ribbon mark, not a vector file. PNG and ICO exports are raster assets.

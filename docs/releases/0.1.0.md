# LinkForge 0.1.0

首个公开测试版本，提供 Windows 10/11 x64 安装包。

## 本版本

- 按 CFST 默认模型完成本机到 Cloudflare 边缘 IP 的延迟、丢包和下载测速；
- 支持结果筛选、CSV 导出、本地测速历史及历史清理；
- 支持 3X-UI 账号登录、保存凭据、客户端选择和关联节点读取；
- 支持本地订阅生成，以及可配置的兼容 goodip 服务发布；
- 提供 VMess / VLESS / Trojan 节点预览与 Auto、Clash、V2rayN、Shadowrocket、Surge 输出。
- 项目以 GNU GPLv3 发布，源码和许可证随仓库提供。

## 已知限制

- 首发平台为 Windows x64；
- 3X-UI 账号登录依赖目标面板可访问并接受当前 TLS 配置；
- 在线订阅发布服务由用户自行配置，默认服务不属于本项目；
- 版本仍属于 MVP，建议先在非生产配置上验证节点和订阅结果。

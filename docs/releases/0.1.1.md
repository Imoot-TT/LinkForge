# LinkForge 0.1.1

本次补丁版本继续提供 Windows x64 安装包，统一品牌图标并完善桌面端界面细节。

## 本版本

- 将应用、桌面快捷方式、安装程序、卸载程序及平台资源统一替换为 LinkForge Windows 图标包；
- 更新网页标题、语言元数据和 favicon，统一显示为 LinkForge；
- 优化确认弹窗和订阅生成历史布局，改善按钮对齐、列间距和成功/失败状态显示；
- 保持本地历史、订阅生成、3X-UI 集成和现有安全行为不变。

## 已知限制

- 首发平台为 Windows x64，安装包暂未进行代码签名；
- 3X-UI 和在线订阅发布仍需要目标服务可访问并由用户自行配置。

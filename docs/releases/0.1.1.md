# LinkForge 0.1.1

Windows x64 patch release focused on the LinkForge brand assets and desktop UI polish.

## Changes

- Replaced the default Tauri/Vite icons with the LinkForge Windows icon pack across the app, shortcut, installer, uninstaller, and platform assets.
- Updated the web app title, language metadata, and favicon to LinkForge.
- Refined confirmation dialogs and subscription-history layout for clearer alignment and status visibility.
- Kept the existing local history, subscription generation, 3X-UI integration, and security behavior unchanged.

## Known limitations

- Windows x64 only; installers are not code-signed.
- 3X-UI and online publishing still require a reachable, user-configured service.

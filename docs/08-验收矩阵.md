# IPTools 验收矩阵

> 版本：0.1.0 · 2026-11-19
>
> 本矩阵把《01-产品需求文档》中的 F-01～F-10 与当前实现、自动化测试和人工验证状态对应起来。`已实现` 表示代码和测试证据已经存在；`待真实验证` 表示需要用户的真实 3X-UI 或真实第三方服务；`受外部能力限制` 表示当前产品无法单方面保证。

## 1. 功能验收

| 需求 | 当前状态 | 实现证据 | 自动化/人工证据 | 剩余事项 |
|---|---|---|---|---|
| F-01 Cloudflare IP 优选 | 已实现，真实公网行为仍需抽样复核 | `app/src-tauri/src/lib.rs` 原生候选生成、TCP 延迟、下载测速；`app/src/App.tsx` 普通流程默认使用 CFST 地址 | Rust 测试覆盖 CFST 默认地址、候选 CIDR 和重定向下载；本机 `ip.txt` 与默认网段已核对 | 不同网络环境下速度可能为 0，需按 CFST 语义解释并用 `speedMin` 筛选 |
| F-02 测速参数 | 已实现 | `SpeedParams`、预设、IPv4/IPv6、并发/次数/延迟/丢包/速度/下载时长和高级参数 | `cargo test` 通过参数校验和默认行为测试 | 仍需在用户机器上确认窗口尺寸下的最终视觉密度 |
| F-03 测速任务 | 已实现 | `start_speed_test`、取消令牌、阶段进度、SQLite 任务状态和异常恢复 | Rust 测试覆盖取消、本地 HTTP 测速和异常任务恢复 | 无；正式发布前建议补充长时间压力测试 |
| F-04 结果管理 | 已实现 | 结果表、搜索、排序、Top N、分页、CSV、载入和重跑见 `app/src/App.tsx` | Rust 测试覆盖 CSV/历史；前端 `npm run build` 通过 | 大量结果和极长 IP/地区文本需要用户机器复核 |
| F-05 节点导入 | 基本实现 | VMess/VLESS/Trojan、逐行/Base64、脱敏预览见 `parse_nodes` 和订阅页 | Rust 测试覆盖解析、Host/SNI 和字段保留 | Reality、特殊参数和更多客户端格式仍需扩充样例 |
| F-06 发布与本地兜底 | 已实现，第三方真实合约待验证 | 本地链接/Base64/Mihomo/Surge 导出；可配置 HTTPS goodip 兼容服务、风险确认、二维码和脱敏预览 | Rust 测试覆盖响应白名单、响应上限、SSRF 防护和脱敏摘要；虚构节点 mock 已验证 | 需要用户提供可测试的 goodip 兼容接口，确认实际请求字段和返回字段 |
| F-07 3X-UI 连接 | 已实现，真实面板待验证 | CSRF/账号密码/2FA、Bearer Token、Windows Credential Manager、客户端列表和 `clients/links/{email}` 见 `three_xui_*` 命令 | Rust 测试覆盖登录表单、Cookie、Token、客户端兼容响应；匿名面板端点已探测 | 使用用户真实账号执行一次只读登录和 `mt` 客户端读取 |
| F-08 节点组合预览 | 已实现 | 节点 × 优选 IP 笛卡尔组合、端口、Host/SNI、差异预览和格式告警 | Rust 测试覆盖 VMess/VLESS/Trojan 字段保留；前端构建通过 | 需要真实节点样例验证客户端导入兼容性 |
| F-09 固定订阅更新 | 受外部能力限制 | 当前提供本地生成和一次性 goodip 发布；未伪造固定 URL、更新、撤销或回滚能力 | PRD 明确要求自有发布服务或完整管理 API | 建设可控订阅后端，定义订阅 ID、版本、更新、撤销和回滚协议 |
| F-10 历史与诊断 | 已实现 | SQLite 保存测速/任务/订阅摘要；筛选、载入、重跑、脱敏诊断和“清空历史”见 `App.tsx` 与 `clear_history` | Rust 测试覆盖脱敏摘要和事务清理；前端显示测速历史和折叠订阅历史 | 需要在用户机器确认旧数据库迁移和大量历史的滚动表现 |

## 2. 安全与发布验收

| 项目 | 状态 | 证据或限制 |
|---|---|---|
| 账号密码/3X-UI Token | 已实现 | 使用 Windows Credential Manager；密码不返回前端、不写入 SQLite/localStorage |
| 订阅节点和 URL 脱敏 | 已实现 | 诊断包、历史摘要和预览均不保存完整节点凭据；在线预览有字段白名单 |
| goodip SSRF 防护 | 已实现 | 仅 HTTPS、解析并拒绝回环/私网/链路本地/ULA 地址、禁止跟随不受控重定向 |
| 测速不依赖 `cfst.exe` | 已实现 | Rust 内核独立实现；运行过程不启动或读取外部可执行文件 |
| 前端构建 | 已验证 | `npm run build` 通过 |
| Rust 格式、测试、静态检查 | 已验证 | `cargo fmt -- --check`、`cargo test`（27 项）、`cargo clippy --all-targets -- -D warnings` 通过 |
| 依赖审计 | 已验证但有维护性警告 | `npm audit --omit=dev` 无漏洞；`cargo audit --no-fetch` 无当前可利用漏洞，但有 6 个上游维护/健壮性警告 |
| 安装包 | 已生成，未签名 | NSIS/MSI 均可启动；正式发布前仍需代码签名、版本策略和发布渠道 |

4. 代码签名并重新记录签名信息、安装包哈希和升级/卸载验证结果。

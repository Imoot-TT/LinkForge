# IPTools 开发与安全审计报告

> 审计日期：2026-11-19  
> 当前版本：0.1.10  
> 结论：可运行的 MVP 开发版，尚未达到正式发布标准

## 1. 已有证据

- Windows 安装包可由 Tauri release 构建生成；
- 前端 `tsc + vite build` 通过；
- Rust 单元测试 27 项通过，其中包含 CFST 默认 URL/自定义 URL 选择、CFST 重定向下载、本机 `ip.txt` 候选生成、SQLite、异常任务恢复、3X-UI 登录/凭据序列化/客户端响应兼容解析、会话 Cookie、分享链接、发布响应安全校验、公网发布地址与私网拒绝、本地 HTTP 测速与取消、订阅历史脱敏摘要、历史清理事务，以及 Mihomo/Surge 字段保留测试；
- `cargo clippy --all-targets -- -D warnings` 通过；
- `npm audit --omit=dev` 为 0 个生产依赖漏洞；完整开发依赖扫描仍报告 Vite 工具链引入的 4 个 high 级 picomatch ReDoS 告警，当前 `npm audit fix` 无法消除；
- `cargo audit --no-fetch` 未报告可利用漏洞；SQLite 依赖曾发现的 `RUSTSEC-2026-0459` 已通过升级到 `rusqlite 0.43 / libsqlite3-sys 0.40` 消除。当前剩余 6 个允许警告：5 个间接依赖停止维护，另一个 glib 告警属于非 Windows 图形栈的间接依赖；正式发布前仍需跟随 Tauri 上游升级复核；
- 测速过程不读取或启动外部 `cfst.exe`；
- 发布服务强制 HTTPS，TLS 证书验证未关闭；
- API Key 只保存在 React 会话状态，保存设置时主动排除；
- 3X-UI Token 以及用户明确选择保存的账号密码进入 Windows Credential Manager；密码不会返回前端，也不写入应用配置、localStorage 和 SQLite；面板/发布请求继承 Windows 系统代理，测速请求强制直连；
- 节点预览只返回协议、名称、地址、端口、TLS、传输和脱敏后的 Host/SNI，不返回 UUID 或密码；
- 第三方发布前仍要求用户确认。

## 3. 安全发现

### 已处理

- 不执行用户提供的程序路径，消除了外部命令注入和二进制替换风险；
- 网络测速通过 reqwest 的域名解析覆盖连接候选 IP，HTTPS 仍使用原域名进行证书和 SNI 校验；
- 在线发布禁止 HTTP；
- 节点密钥不写入 localStorage；
- 普通节点格式错误只显示 `协议://***`；
- 生成数量限制为 500，避免意外组合爆炸。

### 发布前必须处理

1. 3X-UI Token 已接入 Windows Credential Manager；发布服务 API Key 仍仅限当前会话，后续若需要持久化必须复用系统凭据库；
2. 发布接口已有 1 MiB 响应限制，并校验已知响应结构、链接数量、长度和允许协议；仍需用虚构节点验证第三方真实字段命名；
3. 自定义发布地址已拒绝私网/本机解析结果并禁止重定向；正式发布前仍需补充 DNS 重绑定的持续解析监测和用户风险提示；
4. 跟随 Vite/Tauri 上游升级，消除或重新评估已记录的开发依赖及跨平台间接依赖告警；
5. 对安装包进行代码签名，并生成、发布 SHA-256；
6. 用虚构节点执行 goodip 合约测试，不使用真实节点做自动化测试；
7. 增加日志脱敏回归测试、取消/超时集成测试和本地 HTTP 测速服务夹具。

## 4. 当前已知限制

- 下载响应包含 `CF-Ray` 时会提取机房码；TCP-only 或没有该响应头时显示 `N/A`；
- 一个 IPv4 `/24` 随机抽取一个候选；IPv6 每个前缀随机抽取一个候选，属于抽样而非穷举；
- HTTPing 使用 HEAD；不接受 HEAD 的源站可能需要回退到小范围 GET；
- 下载测速当前依次测量筛选后的候选，尚未提供总流量上限；
- 在线服务的真实账号/节点仍未用于自动化测试；goodip 字段合约已用保留测试节点完成只读结构验证；
- 3X-UI 已支持按客户端精确读取关联节点；当前实现依据官方 v3.11 API 与兼容解析测试，仍需使用用户账号在真实面板执行只读验证。

## 5. 审计结论

当前版本已经证明桌面端主链路的技术可行性，但不能标记为正式产品完成。下一开发顺序建议为：虚构节点的第三方真实合约验证 → 取消、超时和无网络端到端故障测试 → 干净 Windows 安装/升级/卸载验证 → 签名发布。

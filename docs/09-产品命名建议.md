# 产品命名建议

## 1. 命名定位

产品实际提供的是一条完整桌面工作流：

```text
Cloudflare 边缘 IP 测试 → 优选入口 → 3X-UI 节点组合 → 订阅生成
```

因此名称应表达“边缘链路选择与自动编排”，不应把产品限定成：

- 只运行 `cfst.exe` 的终端界面；
- 只管理 3X-UI 的面板客户端；
- 只依赖 `goodip.supconit.cc.cd` 的发布工具；
- Cloudflare 的官方产品或官方客户端。

## 2. 推荐名称

### LinkForge（中文名：链路工坊）

这是当前最推荐的名称。

- `Link`：对应节点、优选 IP 和订阅之间的链路；
- `Forge`：对应把原始节点与优选入口组合成可用订阅的工作台；
- 不绑定 CFST、3X-UI 或 goodip，未来替换测速源、面板和发布服务时仍然成立；
- 适合桌面应用标题、安装包和后续跨平台版本。

建议界面展示为：

```text
LinkForge
链路工坊 · IP 优选与订阅工作台
```

## 3. 备选名称

| 名称 | 适合方向 | 取舍 |
|---|---|---|
| EdgePilot（边缘领航） | 偏品牌化、自动化工作流 | 有边缘网络联想，但不如 LinkForge 直接表达节点组合 |
| EdgeRoute（边缘路由） | 偏技术、网络工具 | 准确，但容易让人误解为路由器或代理内核 |
| EdgePick（边缘优选） | 直接表达 IP 筛选 | 易懂，但产品后半段的节点和订阅能力体现较弱 |
| LinkForge（链路工坊） | 强调节点组合和订阅生成 | 品牌感较强，但第一次看到不容易理解 Cloudflare 优选 |
| YouLink（优链） | 中文用户、轻量工具 | 简短好记，但同名产品和域名冲突风险较高 |
| EdgeFlow（边缘流） | 强调自动化工作流 | 现代，但“优选 IP”含义不够直接 |

## 4. 不建议采用

- `IPTools`：描述过于宽泛，搜索和品牌识别度弱；
- `CFST GUI`、`CloudflareSpeedTest Desktop`：容易造成官方关联或第三方项目衍生品误解；
- `3XUI 优选工具`：将产品范围错误地缩小到单一面板；
- `GoodIP Generator`：把第三方发布服务误认为产品核心，并且不利于后续替换服务。

## 5. 实施建议

`LinkForge` 已完成首轮改名：UI 标题、Logo、导航、步骤标题、导出文件名、Cargo/npm 包名和可执行文件均已切换。以下兼容标识仍然保留旧值：

- Tauri bundle identifier：`cc.supconit.iptools`；
- 本地设置、历史数据库和 Windows 凭据服务键：`iptools.*`。

保留这些兼容标识可以让旧版的设置、历史和凭据在升级后继续可用；不影响用户看到的产品名称或安装包名称。

在正式发布前，还应检查商标、域名、GitHub 仓库和应用商店中的同名情况；本文件只是产品命名建议，不构成商标可用性结论。

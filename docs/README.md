## 产品一句话定义

LinkForge（链路工坊）是面向自建 Xray/3X-UI 用户的 Windows 桌面工具。软件按 CFST 默认模型测试本机到边缘 IP 的延迟、丢包和下载速度，再将优选 IP 与 3X-UI 节点组合并生成订阅。

## 当前核心决策

- 首发平台：Windows 10/11 x64；
- 测速内核：应用内置 Rust 实现，不依赖 `cfst.exe`；
- 节点协议：首版支持 VMess、VLESS、Trojan；
- 3X-UI：支持账号安全保存与自动登录、API Token、按客户端选择关联节点，手工粘贴作为降级入口；
- 订阅发布：首版可选调用兼容 goodip 协议的可配置服务，同时必须提供本地生成/导出兜底；
- 订阅形态：目标为固定 URL、内容可更新；
- 技术栈：Rust + Tauri（Windows 首发，保留后续跨平台空间）；
- 安全原则：面板令牌、节点链接和订阅 URL均视为敏感凭据。

## 已确认的外部约束

- `goodip.supconit.cc.cd` 不是用户部署的服务，用户没有该线上实例的管理权限；
- 对应实现存在公开的 MIT 项目 `InfiCheesy/cloudflaresub`，可审阅并用于后续本地生成或自建服务；
- 不能依赖其增加账号、API Key、固定订阅更新、删除或数据迁移能力；
- 调用该服务意味着把完整节点内容发送给第三方，产品必须明确提示并允许关闭；
- 架构必须通过 `SubscriptionPublisher` 接口隔离该服务，避免供应商锁定。
- 用户可以修改发布服务 Base URL 和生成接口路径；替代服务必须兼容既定请求/响应合约，否则需要单独的适配器。

## 产品主链路

```text
连接或导入原始节点
        ↓
运行内置 Rust 测速内核（默认行为对齐 CFST）
        ↓
筛选 Top N 优选地址
        ↓
预览节点与地址组合
        ↓
发布或更新订阅
        ↓
复制、扫码或导入客户端
```
